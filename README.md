## Структура
slozhno-sosredotochitsya-fd/
├── .github/ # GitHub-конфигурация (workflows, шаблоны)
├── fonts/ # локальные файлы шрифтов
├── images/ # медиа: картинки для секций
├── scripts/ # JavaScript-логика (переключение темы и т.п.)
├── styles/ # стили, разбитые по модулям
│ ├── variables.css # переменные (цвета, шрифты, отступы)
│ ├── globals.css # сброс и общие стили
│ ├── fonts.css # подключение шрифтов
│ ├── style.css # основная стилизация страницы
│ ├── dark.css # переопределения для тёмной темы
│ └── light.css # переопределения для светлой темы
├── index.html # HTML-разметка страницы
└── README.md # эта документация

## Функциональность
- **Переключение темы**: кнопки «День», «Авто», «Неон» в шапке. Тема сохраняется между посещениями.
- **Адаптивная сетка**: на экранах ≥1024 px изображения выстраиваются в сетку с помощью CSS Grid; на мобильных — в колонку.
